# Bluebox CLI releases

Releases of the `bluebox` command-line interface for [Bluebox](https://bluebox.ai). This repository holds no source code: each release carries the CLI builds for macOS, Linux and Windows and their checksums.

## Install

See the [CLI reference](https://docs.bluebox.ai/cli).

## Contributing

The contents of this repository are published by the Bluebox release workflow. Pull requests are not accepted.

## Help

To report a problem or get help, see [Get help](https://docs.bluebox.ai/getting-help).
